# SkyChartExporter

プレートソルブ済みの画像から、次の内容を **1枚の軽量な横長 PDF** にまとめて書き出す PixInsight スクリプトです。

- アノテーションを書き込んだ写真（書き込み量はプリセットまたは個別に選択）
- 天球上の位置を示す星図（撮影範囲を赤枠で表示。星図の範囲は自由に指定）
- 基本データ（中心座標・星座・視野・画素スケール・焦点距離・回転角・撮影データ）
- 写っている天体とその種類の一覧
- メモ（ダイアログで記入）

日本語と英語に対応しています。日本語モードでは、日本語名がある天体（メシエ天体、主な NGC/IC 天体、Sh2・LBN などの通称付き天体、明るい恒星、88星座）は日本語で表示します。

## 動作環境

- PixInsight **1.9.6 以降**（V8 スクリプトエンジンと `PDF` オブジェクトを使用）
- インターネット接続は不要です。使うデータは次のとおりです（すべてローカル）。

| データ | 用途 | 無い場合 |
|---|---|---|
| **Stellarium**（インストール済みのもの） | 星雲・星団・銀河 約9.5万天体と、その通称・日本語訳 | PixInsight 同梱カタログ（約1.2万天体）で動作 |
| **Gaia DR3**（SPCC 用の XPSD データベース） | 星図の恒星（7〜9等級まで） | 同梱の恒星カタログ（約3,800星）で描画 |
| PixInsight 同梱データ | 恒星名・星座線・星座境界 | （必須・常にあり） |

### Stellarium のカタログで増える天体

Stellarium の DSO カタログ（`nebulae/default/catalog.dat`）を実行時に読み込みます。データは再配布せず、利用者の Stellarium から読むだけです。

| 種類 | 主なカタログ |
|---|---|
| 散光星雲 | Sh2（シャープレス）, LBN, vdB, RCW, Ced, DWB, vdBH |
| 暗黒星雲 | Barnard, LDN |
| 惑星状星雲 | PK, PN G（NGC/IC 以外の小さなものを含む） |
| 散開星団 | Collinder, Melotte, Trumpler, Stock, Ruprecht, vdB-Ha |
| 銀河 | PGC, UGC, ESO, Arp, VV, HCG |
| 銀河団・超新星残骸 | Abell, SNR G |

通称は Stellarium の `names.dat`、日本語訳は Stellarium の日本語翻訳ファイル（`stellarium-sky/ja.qm`）から取ります（例: LBN 437 ヤモリ星雲、Sh2-129 コウモリ星雲）。国内で定着している名前（胎児星雲・まがたま星雲など）は本スクリプトの辞書が優先です。

Stellarium は `/Applications/Stellarium.app`（Windows は `C:\Program Files\Stellarium`、Linux は `/usr/share/stellarium`）を自動で探します。別の場所にある場合はダイアログの「カタログ」欄で指定してください。

### Gaia（星図の恒星）

PixInsight の Gaia プロセスで、SPCC 用に登録済みの Gaia DR3 データベースを検索します。普段 SPCC を使っていれば設定は不要です。検索できなかった場合に限り、ダイアログの「Gaia XPSD フォルダ」に指定したフォルダの XPSD ファイルを Gaia プロセスに登録してから検索します（PixInsight の Gaia プロセスの設定が更新されます）。星図の半径が 36° を超える場合は、検索に時間がかかるため Gaia を使いません。

## インストール

フォルダ構成をそのまま保ってください（`SkyChartExporter.js` と `lib/` が同じ場所に必要です）。

```
skychartexporter/
├── SkyChartExporter.js   ← 本体（これを実行・登録する）
└── lib/                  ← 部品（SCE-*.jsh）
```

**すぐに使う場合**: PixInsight のメニュー *Script > Execute Script File...* で `SkyChartExporter.js` を選びます。

**メニューに登録する場合**: *Script > Feature Scripts...* で *Add* を押し、このフォルダを指定して *Done*。以後 *Script > Utilities > SkyChartExporter* から起動できます。

## 使い方

1. ImageSolver などでプレートソルブした画像を開き、アクティブにします。
2. スクリプトを起動します。
3. ダイアログで設定して **プレビュー** で確認し、**PDFを書き出す…** で保存します。

設定は次回起動時に引き継がれます（タイトルとメモは画像ごとの内容なので保存しません）。

### 書き込み量プリセットの目安

| プリセット | 天体 | 恒星名 | 図形 |
|---|---|---|---|
| 最小 | メシエ・コールドウェル・通称のある天体 | 2.5等まで | 方位・スケール |
| 標準 | ＋ NGC/IC（12等まで）・散光星雲・散開星団・超新星残骸 | 4.5等まで | ＋ 星座線・グリッド |
| 詳細 | ＋ NGC/IC（14等まで）・暗黒星雲・惑星状星雲・銀河（14等まで） | 6等まで | ＋ 星座境界・星座名 |
| すべて | ＋ 銀河団、NGC/IC・銀河すべて | すべて | すべて |

NGC/IC 以外のカタログ（散光星雲〜銀河団）は、Stellarium のカタログを使っているときだけ対象になります。

## PDF の内容と軽さについて

- 写真以外（注記・星図・文字）は**ベクター**で描くため、拡大してもぼやけず、ファイルサイズにほとんど影響しません。PDF の文字は検索・コピーできます（フォントはサブセット埋め込み）。
- PDF のサイズはほぼ写真の画素数で決まります。目標サイズを超えると、写真の解像度を自動で下げて作り直します（最大7回、下限 50 dpi）。それでも収まらない場合は警告を出します。
- 書き出し結果（サイズ・写真の画素数・解像度）はメッセージとコンソールに表示されます。

## 基本データの見方

- **中心座標**: 画像中心の赤経・赤緯（天測解の座標系。通常は ICRS ≒ J2000）
- **星座**: 画像中心が属する星座（星座境界データから判定）
- **焦点距離**: 下記「焦点距離について」を参照
- **回転角**: PixInsight の天測解の表示と同じ値。鏡像なら「（鏡像）」
- **撮影日時・露出・機材**: FITS キーワード（`DATE-OBS`, `EXPTIME`, `NCOMBINE`, `TELESCOP`, `INSTRUME`, `FILTER` など）または XISF プロパティから、あるものだけ表示します

### 焦点距離について

焦点距離は「だいたい分かれば十分」という考えで、次の順に求めます。基本データには、どの方法で求めたかを併記します。

1. ダイアログで手入力した焦点距離
2. 画像に記録された焦点距離（FITS の `FOCALLEN` など）
3. 画素サイズが分かれば、画素スケールから算出（画素サイズは、手入力 → 画像の記録 → 同じカメラで前回入力した値 → カメラ名からの推定、の順に探す）
4. それも無ければ、**視野から35mm判換算で推定**（例: 「約 112 mm（35mm判換算・視野から推定）」）

4 の換算は、対角の視野が同じになる35mm判（フルサイズ、対角 43.3 mm）のレンズの焦点距離です。

> 焦点距離 ≈ 43.3 mm ÷ (2 × tan(対角視野 ÷ 2))

APS-C や天体用の小さなセンサーで撮った画像では、実際の焦点距離より長めの値になります（APS-C ならおよそ 1.5 倍）。実際の値を載せたい場合は、焦点距離か画素サイズを手入力してください。画素サイズはカメラごとに記憶します。

ImageSolver でソルブした画像では、PixInsight が `FOCALLEN` を実効焦点距離で書き換えるため、レンズの公称値（例: 135 mm）とわずかに異なることがあります。

### ページの割付

- **右列**: 星図（上）と、写っている天体の一覧（下、縦長）。一覧は文字を省略せず、名前が長いときは次の行に折り返します。入りきらない分は最後に「ほか N 天体」とまとめます。
- **左列**: 写真。基本データとメモは、横長の写真なら写真の下、縦長の写真なら写真の右に置きます（写真を大きく取れる方を自動で選びます）。基本データの長い値も折り返して表示します。

## 制限事項

- 超広角の画像で「詳細」「すべて」を選ぶと、NGC/IC 天体や恒星名が非常に多く書き込まれます。広角では「最小」か「標準」、または NGC/IC の限界等級を下げるのがおすすめです（重なるラベルは自動的に省略されます）。

- Gaia が使えない場合や星図の半径が 36° を超える場合、星図の恒星は同梱の恒星カタログ（約3,800星、概ね6等級まで）だけになります。
- Stellarium が無い場合、天体は PixInsight 同梱のカタログ（Messier / NGC-IC / Caldwell / SNR ほか）だけになり、Sh2 などは代表的なもののみです。
- 天体の位置・大きさ・種別は各カタログの値です。Stellarium の LDN・LBN などの「等級」欄は不透明度・明るさの階級なので、等級による絞り込みには使っていません。
- 日本語名は、本スクリプトの辞書（国内で定着している名前）を優先し、無いものは Stellarium の日本語訳を使います。Stellarium の訳には直訳調で国内では一般的でないもの（例: 大皿に乗った魚、ランプスター）も含まれます。日本語名が無い天体は英語の通称、またはカタログ番号で表示します。
